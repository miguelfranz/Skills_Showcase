# 📌 Description

A responsive personal portfolio website showcasing my skills, selected projects, and contact information as a Computer Science student and UI/UX designer. The website includes a dark/light mode toggle and responsive layouts for different screen sizes.

🛠️ Technologies Used

React

Vite

JavaScript

HTML

CSS

Git and GitHub

# ✨ Features

Home, Projects, and Contact sections

Responsive design for desktop and mobile

Dark/light mode toggle

Project showcase

Contact form interface

# ⚙️ Setup Instructions

## Prerequisites

Install Node.js and Git.

## Installation

### Clone this repository:

git clone YOUR_GITHUB_REPOSITORY_URL

### Navigate to the project folder:

cd skills_challenge

### Install dependencies:

npm install

### Start the development server:

npm run dev

Open the local URL displayed in your terminal.
